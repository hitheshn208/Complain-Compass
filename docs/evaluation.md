## Caveats

- The dataset is synthetic and template-based: each issue family is written with a limited set of paraphrase templates, so embeddings form tighter sub-clusters than real-world text. Real data will differ.
- Without an OpenAI key, severity comes from the keyword fallback in `app/inference/classifier.py`. Those rules and the dataset templates were written by the same author, so the fallback severity score is optimistic and should not be read as a general-purpose benchmark.
- The ground-truth ranking uses the same priority formula as the system, so NDCG measures how well clustering + dedup + classification recover the ranking that perfect labels would produce - not whether the formula itself matches business judgement.
- GPT-based severity/labels are only evaluated when `OPENAI_API_KEY` is set; that run is not included here unless 'LLM used' above says yes.
